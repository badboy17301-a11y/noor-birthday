# Noor Malik Birthday Website

A lightweight, mobile-friendly interactive birthday surprise made with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Download or unzip this folder.
2. Open `index.html` in a modern browser.
3. For a closer-to-hosted preview, use VS Code's Live Server extension (optional).

## Publish free with GitHub Pages
1. Sign in to GitHub or create a free account at https://github.com/.
2. Create a **public** repository named `noor-birthday`.
3. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
4. Open the repository's **Settings** tab.
5. Select **Pages** in the sidebar.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Choose branch `main` and folder `/ (root)`, then click **Save**.
8. Wait a few minutes and refresh the Pages settings. GitHub will show the published URL, usually:
   `https://YOUR-USERNAME.github.io/noor-birthday/`
9. Open that link on your phone to test it, then send the link to Noor.

## Notes
- Hosting a basic static site on GitHub Pages is free.
- The repository and website are public. Don't add private information.
- The Google Fonts import is optional; if unavailable, system fallback fonts are used.
- No music, photos, tracking, login, backend, or database is used.
- To edit messages, change the text in `index.html`. To change the colors, edit the CSS variables at the top of `style.css`.
